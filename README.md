# AI Atelier

GitHub Pages 주소에서 `index.html`이 바로 열립니다. `introduce.html`, `기사.html`, `이미지.html`, `영상.html`, `파이널.html`은 상단 메뉴로 이동할 수 있습니다. 함께 제공한 `style.css`, `site-additions.css`, `app.js`, `assets` 폴더를 같은 위치에 유지해 주세요.

임시 글과 페이지 구성은 `dist/app.js`, 디자인은 `dist/style.css`에서 수정합니다. 외부 Google Fonts에 연결되지 않으면 시스템 글꼴로 표시됩니다.

자료 미리보기는 선택한 파일을 현재 페이지에서만 표시합니다. 영구 저장이나 서버 업로드 기능은 포함하지 않습니다. 실제 공개 업로드 서비스를 운영하려면 관리자 인증 및 파일 저장 서버를 연결해야 합니다.

이미지는 AI 생성 예시이며 영상은 기획 예시입니다. 모든 문구는 교육용 임시 콘텐츠입니다.
